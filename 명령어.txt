현재 youth-support-app 프로젝트는
- index.html / logic.js / data/policies.js / data/profiles.js 분리 완료
- test.html 18개 테스트 통과 완료
- 정책 15개 입력 완료

이제 배포 가능한 MVP 마감 작업을 진행해라.

작업 순서:
1. 수동 QA 체크리스트를 markdown으로 작성
   - 온보딩, 대시보드, 목록, 상세, 알림함 기준 15개 시나리오
   - 샘플 프로필 5개별 기대 결과 포함

2. policies.js 스키마를 확장
   - reviewStatus
   - lastVerifiedAt
   - nextReviewAt
   - sourcePlatform
   - contactPoint
   - visibility
   - applicationMethod
   - updatedNote
   기본값도 함께 정의

3. index.html UX 개선
   - 정책 카드에 추천 이유 한 줄 추가
   - 정책 상세 상단에 '다음 행동' 박스 추가
   - 대시보드에 '지금 바로 신청', '이번 주 마감', '기관 확인 필요' 요약 카드 추가

4. PWA 기본 적용
   - manifest.json
   - service-worker.js
   - 홈 화면 설치 가능 구조
   - 기본 오프라인 캐시
   - 앱 아이콘 경로 자리 표시

주의:
- 기존 logic.js 순수 함수 구조는 유지
- data 파일을 소스 오브 트루스로 유지
- React 전환 가능성을 해치지 않도록 DOM 의존 코드를 logic.js에 넣지 말 것
